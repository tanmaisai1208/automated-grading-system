# Project Title

## 1. Introduction
This is a dashboard web application where users can view courses, upload marks, and manage academic data.

## 2. Technologies Used
### Frontend
- React.js (v19)
- React Router DOM
- Vite

### Styling
- CSS

### Development Tools
- ESLint

## 3. Installation (Dependencies)
Install all required dependencies:
frontend dependencies:
```bash
npm install

backend dependencies:
cd backend
npm install

## 4. How to Run the Project
 Install Dependencies
```bash
npm install

Frontend Server
npm run dev

The application will run at:
http://localhost:5173

Backend Server
cd backend
npm run dev

## 5. Website Pages & Usage
Website Pages & Functionality
Dashboard Page

Main page of the application

Provides navigation to different sections

Displays overview of data

Previous Courses Page

Shows list of completed courses

Helps users review past academic records

Upload Marks Page

Allows users to upload or update marks

Stores and manages academic performance data
